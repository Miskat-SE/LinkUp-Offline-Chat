# ADR-0008: One Kotlin platform bridge, typed with pigeon

- **Status:** Accepted
- **Date:** 2026-10-08
- **Plan decision:** D8

## Context

Several needs have no suitable plugin: network binding, multicast lock, the foreground service and its notification, Wi-Fi/wake locks, video thumbnails, opening and sharing files.

## Decision

One Kotlin plugin inside `android/app`, with a Dart/Kotlin interface generated by `pigeon`. P0 vetting: `open_filex` was last released in March 2025 (fails the 12-month rule), so opening and sharing files also go through the bridge with a `FileProvider`.

## Consequences

Fewer third-party plugins; typed calls instead of string channel names.
