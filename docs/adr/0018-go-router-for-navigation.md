# ADR-0018: go_router for navigation

- **Status:** Accepted
- **Date:** 2026-10-08
- **Plan decision:** D18

## Context

About 14 screens, plus notification taps that should open a chat or a transfer.

## Decision

Use `go_router` (flutter.dev).

## Consequences

Declarative routes with deep links; already built on `material_ui`.
